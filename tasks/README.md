# Tasks

One-responsibility tasks. A feature's `TASKS.md` lives here, e.g.:

```
tasks/platform-auth/TASKS.md
  001 Create AuthUser table
  002 RegisterUser command
  003 Login command + JWT
  004 RefreshToken rotation
  005 Audit login
  006 Permission guard on endpoints
  007 Tests
```

Each task: one responsibility, small enough to implement, analyze, and test in one step.
